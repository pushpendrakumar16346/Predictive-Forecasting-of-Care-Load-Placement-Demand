# User Guide

## Purpose

The dashboard supports historical monitoring, forecasting and care-load
planning.

## Dashboard modules

### Historical monitoring

Review historical care-load patterns and changes over time.

### Predictive forecasting

Select an available model and forecast horizon.
Supported horizons are 1, 7, 14 and 30 days.

### Capacity and surge-risk analysis

Review capacity indicators and potential increases in care demand.

### Scenario and model comparison

Compare model forecasts and scenario assumptions.

## Interpreting forecasts

Forecasts are estimates, not guarantees. Review forecast horizon, model
performance, uncertainty and data quality before making decisions.

## Responsible use

Forecasts should support human review and operational decision-making.
