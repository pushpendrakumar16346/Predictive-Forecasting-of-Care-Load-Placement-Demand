# Predictive Forecasting of Care Load and Placement Demand

## Project overview

This project forecasts the number of children in HHS care using time-series
and machine-learning methods. It includes data preparation, model evaluation,
uncertainty analysis, operational KPIs and a Streamlit dashboard.

## Forecasting target

`children_in_hhs_care`

## Forecast horizons

- 1 day
- 7 days
- 14 days
- 30 days

## Dataset

`data/processed/cleaned_care_data.csv`

## Dashboard modules

- Historical monitoring
- Predictive forecasting
- Capacity and surge-risk analysis
- Scenario and model comparison
